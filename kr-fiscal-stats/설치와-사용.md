# 설치와 사용 — 사람이 읽는 문서

이 스킬은 한국 재정·경제·통계 공공 API 다섯 곳에서 자료를 받아 옵니다 —
**지방재정365 · 열린재정 · KOSIS · 한국은행 ECOS · 경기데이터드림.**
클로드에게 「OO시 2024년 세출예산 받아 줘」처럼 말하면, 클로드가 어느 곳에서 받을지 고르고 불러 옵니다.

★**클로드 코드, 또는 클로드 데스크탑의 «코드» 탭(로컬)에서 쓰십시오.**
  데스크탑 «일반 채팅»에 올린 스킬은 스크립트가 Anthropic 클라우드에서 돌아 내 PC 의 키를 못 읽습니다(공식 문서 기준, 2026-10-22 읽음). ChatGPT 웹은 확인 못 함입니다.
★**코덱스**는 같은 꼴을 받습니다 — 스킬 폴더를 `~/.agents/skills` 에 둡니다. 다만 바깥 사이트가 기본으로 막혀 있어 네트워크를 켜야 합니다. 켜는 법과 키를 읽는지는 확인 못 함입니다.

## 1) 인증키 받기 — 쓸 곳만

회원가입·로그인을 한 뒤 아래 주소에서 신청합니다.

| 자료원 | 신청하는 곳 | 키 이름 |
|---|---|---|
| 지방재정365 | https://www.lofin365.go.kr → 위 메뉴 「재정데이터개방」 → 인증키 신청 | `LOFIN_API_KEY` |
| 열린재정 | https://www.openfiscaldata.go.kr/op/ko/ds/UOPKODSA01.do → 인증키 발급 | `OPENFISCAL_API_KEY` |
| KOSIS | https://kosis.kr/openapi/serviceUse/serviceUseUnityReg_01Detail.do → 활용신청 | `KOSIS_API_KEY` |
| 한국은행 ECOS | https://ecos.bok.or.kr/api/#/AuthKeyApply | `ECOS_API_KEY` |
| 경기데이터드림 | https://data.gg.go.kr/portal/openapi/insertApikeyPage.do | `GGDREAM_API_KEY` |

지방재정365는 메뉴를 스크립트로 그려서 바로 가는 주소가 없습니다. 신청 화면 안의 입력 칸은 확인하지 못했습니다(로그인 필요).

★**키를 클로드 대화창에 붙여 넣지 마십시오.** 대화 기록에 그대로 남습니다. 붙여 넣었다면 그 키는 폐기하고 다시 받으십시오.

## 2) 스킬 폴더 넣기

`kr-fiscal-stats` 폴더를 **통째로** 아래 자리에 넣습니다. `skills` 폴더가 없으면 새로 만듭니다. 넣은 뒤 **새 세션**을 엽니다.

| 어디서 | 윈도우 | 맥 |
|---|---|---|
| 클로드 코드 · 데스크탑 «코드» 탭 | `C:\Users\<이름>\.claude\skills\kr-fiscal-stats` | `~/.claude/skills/kr-fiscal-stats` |
| 코덱스 | `C:\Users\<이름>\.agents\skills\kr-fiscal-stats` | `~/.agents/skills/kr-fiscal-stats` |

★`kr-fiscal-stats` 안에 `kr-fiscal-stats` 가 한 번 더 들어가지 않게 합니다. `SKILL.md` 가 바로 보여야 합니다.
★데스크탑 «코드» 탭도 클로드 코드와 같은 폴더를 읽는 것으로 압니다. 직접 확인하지는 못했습니다.

### 「닿지 못했습니다」가 나올 때 — 도메인 허용 목록

클로드 데스크탑은 스크립트가 나가는 주소를 허용 목록으로 막을 수 있습니다. 오류 문장에 넣을 도메인이 적혀 나옵니다.
설정 → **기능** → 「**외부 네트워크 접속 허용**」 켜기 → 「**추가 허용 도메인**」에 쓸 곳의 도메인을 넣고 새 대화에서 다시 합니다.

| 자료원 | 도메인 |
|---|---|
| 지방재정365 | `www.lofin365.go.kr` |
| 열린재정 | `openapi.openfiscaldata.go.kr` |
| KOSIS | `kosis.kr` |
| 한국은행 ECOS | `ecos.bok.or.kr` |

## 키 세팅 — 사용자가 직접 합니다

### 가장 쉬운 길 — 키 넣는 창

클로드에게 「**지방재정365 키 넣어 줘**」처럼 말합니다. 클로드가 창을 띄울지 묻고, 좋다고 하면 이런 창이 뜹니다.

1. «**발급 받으러 가기**» 단추를 누르면 그 자료원의 발급 화면이 열립니다. 회원가입·로그인 뒤 키를 받습니다.
2. 받은 키를 복사해 창의 칸에 붙여 넣습니다(«붙여넣기» 단추나 Ctrl+V, 맥은 ⌘+V). 칸에는 `*` 로 가려 보입니다. «키 글자 보기»를 누르면 보입니다.
3. «**저장**»을 누릅니다. 홈 폴더의 `.lofin_key` 같은 파일에 키만 한 줄 들어갑니다. 이미 있으면 바꿀지 묻습니다.
4. 저장한 뒤 클로드에게 하던 부탁을 다시 하면 됩니다. 새 세션을 열 필요가 없습니다.

★창에 키를 넣으면 대화 기록에 키가 남지 않습니다. 클로드는 키를 보지 않습니다.
★창이 안 뜨는 자리가 있습니다 — 「이 자리에서는 창을 못 띄웁니다」가 나오면 아래 «그 밖에» 길로 넣습니다.
  - 데스크탑 일반 채팅에 올린 스킬은 클라우드에서 돌아 내 화면에 창이 안 뜹니다(공식 문서 기준 — 맨 위 ★ 참고).
  - 맥: python.org 에서 받은 파이썬은 창이 됩니다(Tk 8.6 이 함께 들어 있습니다). 맥에 처음부터 있는 `/usr/bin/python3` 는 옛 Tk 8.5 라 창이 이상하게 그려지거나 멈출 수 있습니다. 홈브루 파이썬은 `brew install python-tk` 를 따로 해야 합니다. 셋 다 맥에서 직접 확인하지는 못했습니다.
  - 윈도우: python.org 에서 받은 파이썬에는 창 기능이 들어 있습니다(설치 때 «tcl/tk and IDLE» 칸을 끄지 않았다면).

### 그 밖에

스크립트는 키를 **두 곳에서만** 찾습니다 — 환경변수, 또는 홈 폴더의 `~/.<이름>_key` 파일. 환경변수가 파일보다 먼저입니다.

**클로드 코드·클로드 데스크탑의 코드 세션** — `settings.json` 의 `env` 칸에 넣을 수 있습니다.
파일은 윈도우 `C:\Users\<이름>\.claude\settings.json`, 맥 `~/.claude/settings.json` 입니다. 이미 다른 칸이 있으면 `env` 칸만 더합니다.
```
{
  "env": {
    "LOFIN_API_KEY": "발급받은 키",
    "OPENFISCAL_API_KEY": "…",
    "KOSIS_API_KEY": "…",
    "ECOS_API_KEY": "…",
    "GGDREAM_API_KEY": "…"
  }
}
```
넣은 뒤 새 세션을 엽니다. 클로드 코드가 이 칸을 환경변수로 넘겨 줍니다.

**운영체제 환경변수** — 윈도우는 「계정의 환경 변수 편집」에서 사용자 변수로, 맥은 `~/.zshrc` 에 `export LOFIN_API_KEY=키`.

**홈 폴더 파일을 손으로** — `~/.lofin_key` 처럼 `~/.<이름>_key` 파일에 키만 한 줄. 창이 하는 일과 같습니다.

키가 없으면 클로드가 창을 띄울지 묻거나, 창이 안 되는 자리면 세팅하는 방법을 알려 드리고 멈춥니다. 키를 대신 받아 넣어 주지는 않습니다.

★2026-09-23 윈도우 노트북의 데스크탑 코드 세션에서 `settings.json` 의 `env` 칸으로 다섯 곳이 다 돌았습니다(한 번). 데스크탑 일반 채팅에 올린 스킬은 공식 문서로는 키를 못 읽습니다(맨 위 ★) — 돌려 보지는 않았습니다.
★2026-10-22 키 넣는 창은 리눅스 가상 화면에서 가짜 키로만 시험했습니다. 윈도우·맥 실기는 아직입니다.
★윈도우에서는 명령의 `python3` 대신 `python` 을 씁니다.

## 4) 스킬이 스스로 고치기를 청합니다

쓰다가 **사이트 목록이 바뀌었거나, 스킬 설명대로 했는데 틀렸거나, 적혀 있지 않은 함정**을 만나면
클로드가 답 끝에 **[스킬 개선 제안]** 을 붙입니다.
- 클로드 코드에서는 클로드가 스킬 파일을 바로 고치고 `references/고친-기록.md` 에 적습니다.
- 스킬 폴더에 쓸 수 없는 자리에서는 **고친 파일을 만들어 드립니다.** 그것을 스킬 폴더에 덮어 넣으십시오.

## 5) 알아 둘 것

- **금액 단위가 대개 적혀 있지 않습니다.** 클로드가 크기로 맞춰 추정하면 「추정」이라고 밝힙니다.
- **더한 값·나눈 값은 원자료에 없는 수**입니다. 클로드가 무엇을 더했는지 밝힙니다.
