# 경기데이터드림 자료 받아오기

경기도가 공개한 공공데이터의 OPEN API(약 2,290개 — 시설·인허가·지원사업·현황 목록 등).
목록은 `references/ggdream-목록.md`(서비스명 · 이름 · 꼬리표).
★**경기도 시군의 «재정»은 여기가 아니라 지방재정365**가 정본이다.

---

## 1. 부르는 모양 — 지방재정365·열린재정과 같은 틀

```
GET https://openapi.gg.go.kr/{서비스명}?KEY={인증키}&Type=json&pIndex={쪽}&pSize={쪽당건수}&{칸이름}={값}
```

- ★인증키 인자 이름이 **`KEY`**(대문자)다. 지방재정365·열린재정은 `Key`.
- `Type` 을 빼면 XML 이 온다. `pSize` 는 1~1000(문서 기준).
- 성공 = `{"서비스명": [{"head": [...]}, {"row": [...]}]}`, 오류·빈결과 = `{"RESULT": {"CODE", "MESSAGE"}}` — 모양이 다르다. HTTP 는 늘 200.

---

## 2. ★반드시 알고 시작할 함정 (2026-09-23 실제로 재 본 것)

### ① ★★**키 없이 부르면 «5행만» 온다 — 오류 없이**

키를 빼거나 비우면 `INFO-000` 과 **전체 총건수**를 주면서 **행은 5개만** 준다. 쪽을 넘겨도 같은 5행이다.
⟹ **「총 N건인데 5행」이면 키 문제다.** 스크립트는 키 없이는 부르지 않는다. (`KEY=sample` 은 `ERROR-290`.)

### ② 「누가 부르나」로 막는다

curl·wget 표식은 HTTP 200 과 함께 「**보안 정책에 의해 차단 되었습니다**」 HTML 을 받는다. 스크립트는 브라우저 표식으로 부른다.

### ③ ★**칸 뜻 표도, 칸을 알려 주는 API 도 없다**

거르개·칸 이름은 **1건을 받아 보고** 안다(`--peek`). 뜻이 이름으로 분명하지 않으면 **짐작하지 말고 모른다고** 말한다.

### ④ 모르는 인자는 조용히 무시된다

`--SIGUN_NM 수원시` 는 먹는다(413,762 → 36,227건). 틀린 칸 이름은 오류 없이 **전체**가 온다 — **총건수가 줄었는지** 본다.
★**거르개가 «부분일치»인 칸이 있다** — `--LOCPLC_ROADNM_ADDR 수원` 은 안산 「연수원로」까지 딸려 왔다. 받은 뒤 그 칸 값을 한 번 확인한다.

### ⑤ 그 밖

- ★**같은 주제의 서비스가 여럿이고 수가 크게 다르다** — 수원시 전기차 충전소: `Elctychrgstatn` 136건 · `ElectricityCarCharging`(제공표준) 충전소 1,975곳(2026-09-23). 목록에서 낱말로 다 찾아 보고, **어느 것을 썼는지와 갱신일**을 밝힌다. 갱신일 칸이 없는 서비스도 있다.
- 어떤 칸은 값이 `{"type", "value", "null"}` 꾸러미로 온다.
- `Type=csv` 는 조용히 XML 을 준다. `http://` 는 503 — 스크립트는 https 로 부른다.

## 3. 응답 코드

| 코드 | 뜻 | 할 일 |
|---|---|---|
| `INFO-000` | 정상 | (행이 5개뿐이면 함정 ①) |
| `INFO-200` | 자료 없음 | 거르개를 넓힌다 |
| `ERROR-290` | 인증키가 유효하지 않음 | 키 확인 |
| `ERROR-310` | 해당 서비스 없음 | 서비스명 오타. 목록에서 다시 찾거나 `대조` |
| `ERROR-500` | 서버 오류 | **목록에서 없어진 서비스도 이것을 준다**(2026-09-23 한 번 확인). 되풀이되면 `대조` |
| `ERROR-337` | 하루 호출 한도 초과(문서·다른 도구 기준, 직접 보지는 못함) | 다음 날 |

---

## 4. 일하는 순서

1. `python3 scripts/ggdream.py search <낱말>` 로 서비스를 찾는다(목록 파일을 훑는다).
2. `python3 scripts/ggdream.py <서비스명> --peek` — 칸 이름·총건수를 본다.
3. 거르개를 넣고 다시 `--peek` — **총건수가 줄었는지** 본다.
4. `--all --csv` 로 받는다. 출처 = 「경기데이터드림(data.gg.go.kr), 경기도 · 받은 날짜」.
