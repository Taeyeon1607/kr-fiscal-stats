# 한국은행 ECOS 자료 받아오기

금리·물가·환율·통화·국민계정(GDP)·국제수지 — 한국은행 경제통계시스템의 **통계표 617개**.
목록은 `references/ecos-목록.md`(통계표코드 · 이름 · 대표 주기 · 기관).

---

## 1. 부르는 모양 — «경로»에 다 들어간다

```
https://ecos.bok.or.kr/api/{서비스}/{인증키}/json/kr/{시작행}/{끝행}/{…}
```

| 하려는 것 | 서비스 | 뒤에 붙는 것 |
|---|---|---|
| 통계표 목록 | `StatisticTableList` | (없음) — 844행이 한 번에 온다(분류 가지 227 + 표 617) |
| 표 하나의 항목·주기·기간·단위 | `StatisticItemList` | `/{통계표코드}` |
| 자료 | `StatisticSearch` | `/{통계표코드}/{주기}/{시작}/{끝}/{항목1}/{항목2}/{항목3}/{항목4}` |
| 100대 주요지표 | `KeyStatisticList` | (없음) |

★**키가 주소 안에 있다** — 주소를 통째로 화면·기록에 남기지 않는다. 스크립트는 오류에 주소를 찍지 않는다.

## 2. ★반드시 알고 시작할 함정 (2026-09-23 실제로 재 본 것)

### ① 오류도 HTTP 200 이고, 모양이 다르다

성공 `{"StatisticSearch": {"list_total_count", "row"}}`, 오류·빈결과 `{"RESULT": {"CODE", "MESSAGE"}}`.
서비스 이름 오타만 **HTTP 404 + HTML** 이다.

### ② ★★**틀려도 «자료 없음»(INFO-200)이다**

**틀린 통계표코드 · 틀린 항목코드 · 아직 없는 기간 · `*` 를 넣은 것** — 전부 진짜 빈 결과와 **같은 INFO-200** 이다.
⟹ INFO-200 이 오면 「자료가 없다」고 답하기 **전에** `ecos.py items <표>` 로 코드와 기간을 확인한다.
(모든 값 자리표시는 `*` 가 아니라 `?` 다.)

### ③ ★**목록의 주기는 «대표 하나»뿐이다**

`722Y001`(기준금리)은 목록에 D(날)로 적혀 있지만 항목은 **A·Q·M·D** 모두 있다.
⟹ 주기는 `items` 로 본다. 항목마다 **시작~끝 기간**도 거기 있다.

### ④ 날짜 모양이 주기마다 다르다 — 틀리면 `ERROR-101`

A `2024` · S `2024S1` · Q `2024Q1` · M `202401` · SM `202401S1` · D `20240101`.
(S·SM 모양은 문서 기준이다 — 실호출로는 A·Q·M·D 만 확인했다.) 스크립트가 부르기 전에 모양을 본다.

### ⑤ ★**항목 묶음(그룹)의 차례가 표마다 다르다 · 단위는 첫 묶음 항목에만 있다**

`141Y002` 는 첫 묶음이 계정항목이고, `141Y006` 은 보고기관이다. **항목코드는 묶음 차례대로** 넣는다(`--항목 A B`).
단위(`UNIT_NAME`)는 **첫 묶음 항목에만** 적혀 있고 나머지는 비어 온다 — 단위가 비었으면 첫 묶음 항목의 단위를 본다.

### ⑥ 항목을 빼면 «모든 조합»이 온다

`141Y002` 한 달치에 항목을 안 주면 232행이 온다. 필요한 항목만 준다. 한 번에 최대 100,000행.

### ⑦ 그 밖

- 값(`DATA_VALUE`)은 **글자**다. 더하기 전에 숫자로 바꾼다.
- `KeyStatisticList` 의 `CYCLE` 칸에는 주기가 아니라 **날짜**가 들어 있다.
- 한글을 주소에 넣으면 인코딩해야 한다(스크립트가 한다).
- 공개 키 `sample` 은 10행까지만 된다(11행부터 `ERROR-301`).

## 3. 응답 코드

| 코드 | 뜻 | 할 일 |
|---|---|---|
| `INFO-000` | 정상 | — |
| `INFO-100` | 인증키가 틀렸거나 비었다 | 키 확인 |
| `INFO-200` | 자료 없음 — **또는 코드·기간이 틀렸다**(함정 ②) | `items` 로 확인 |
| `ERROR-101` | 날짜 모양이 주기와 안 맞는다 | 함정 ④ |
| `ERROR-301` | 행 수 문제(10만 초과·시작>끝·sample 키 10 초과) | 문구가 까닭을 말한다 |

## 4. 일하는 순서

1. **무슨 지표 · 어느 주기 · 어느 기간**을 뽑는다. 빠진 것은 묻는다(특히 주기 — 월인지 해인지).
2. `python3 scripts/ecos.py search <낱말>` 로 통계표를 찾는다(목록 파일을 훑는다. 낱말은 짧게).
   없으면 `대조` 로 목록이 낡았는지 본다.
3. `python3 scripts/ecos.py items <통계표코드>` 로 **항목코드 · 주기 · 기간 · 단위**를 본다.
4. `python3 scripts/ecos.py data <코드> --주기 M --기간 202401 202412 --항목 <항목코드>` 로 받는다.
5. 받은 뒤 **단위**를 확인하고, 출처를 적는다 — 「한국은행 경제통계시스템(ECOS) · 받은 날짜」.
