스크립트는 키를 **환경변수 → 홈 폴더의 `~/.<이름>_key`(예: `~/.lofin_key`)** 두 곳에서만 찾는다.
키가 없으면 **사용자에게 «키 넣는 창을 띄울까요?»라고 묻고**, 좋다고 하면 `python3 scripts/setkey.py <이름>`(윈도우는 `python`)을 돌린다.
- 이름은 `lofin`·`openfiscal`·`kosis`·`ecos`·`ggdream`. 창에는 발급 화면으로 가는 단추와 키 붙여넣기 칸이 있고, 사용자가 직접 붙여 넣고 «저장»을 누른다. 저장하면 `~/.<이름>_key` 에 한 줄로 들어간다.
- 종료코드: **0** 저장함(새 세션 없이 바로 원래 명령을 다시 돌린다) · **1** 저장 안 하고 닫음 · **2** 이름이 틀림 · **3** 창을 못 띄우는 자리(tkinter·화면 없음) · **4** 파일을 못 씀.
- **3 이 나면** 아래 «그 밖에» 길을 알려 주고 멈춘다. 키를 대화창에 붙이라고 하지 않는다.
- 창에 «환경변수가 이미 있어 그 값이 먼저 쓰입니다»가 뜨면, 파일보다 환경변수가 앞서므로 새 키를 쓰려면 그 환경변수를 사용자가 고쳐야 한다.
- **그 밖에 — 세팅하는 법(창을 못 띄울 때 사용자에게 알려 줄 것)**
  - **클로드 코드·클로드 데스크탑의 코드 세션**: `~/.claude/settings.json`(윈도우는 `C:\Users\<이름>\.claude\settings.json`)의 `"env"` 칸에 `"LOFIN_API_KEY": "키"` 처럼 넣고 새 세션을 연다. 클로드 코드가 이 칸을 환경변수로 넘긴다.
  - 그 밖(터미널에서 직접 돌릴 때 등): 윈도우는 「계정의 환경 변수 편집」에서 사용자 변수로, 맥·리눅스는 `~/.zshrc`(또는 `~/.bashrc`)에 `export LOFIN_API_KEY=키`.
  - 파일로 둘 때: 홈 폴더(윈도우는 `C:\Users\<이름>`)에 `.lofin_key` 파일을 만들고 키만 한 줄.
  - ★사용자가 직접 한다. 클로드가 키 값을 받아 명령으로 대신 넣지 않는다.
- **확인된 것** — 2026-09-23 윈도우 노트북의 데스크탑 코드 세션에서 `settings.json` 의 `env` 칸 키로 다섯 곳이 다 돌았다(한 번). 데스크탑 일반 채팅에 올린 스킬에서 되는지는 확인하지 못했다.

★**키는 사용자가 직접 넣는다. 클로드는 키 넣는 창(`setkey.py`)을 띄우거나 세팅하는 법을 알려 줄 뿐이다.** 키를 받아 파일에 적어 주지 않는다.

## 2. 다섯 곳 공통 규칙

1. **첫 호출은 언제나 1건만** — `--peek`(ECOS·KOSIS 는 짧은 기간)으로 칸 이름·총건수·단위를 먼저 본다.
2. **거르개를 넣었으면 총건수가 줄었는지 본다.** 모르는 인자를 **조용히 무시하는** 곳이 있다 — 줄지 않았으면 안 먹은 것이다.
3. **HTTP 상태로 성패를 가르지 않는다.** 다섯 곳 모두 오류를 200(열린재정은 201) 안의 본문으로 준다. 스크립트가 가려 준다.
4. **단위를 단정하지 않는다.** 단위가 안 적힌 자료가 많고, 한 자료 안에서도 칸마다 다르다. 크기로 맞춰 추정했으면 **「추정」이라고 밝힌다.**
5. **예산인지 결산인지, 당초인지 최종인지** 이름으로 가르지 말고 구분 칸을 본다(각 레퍼런스의 함정).
6. **더하거나 나누었으면 그렇게 했다고 밝힌다** — 어느 칸을 더했는지까지. `--sum` 결과는 원자료에 없는 수다.
7. **없는 값을 지어내지 않는다.** 빈 결과는 「그 조건에 자료가 없다」고 말한다.
8. **출처와 받은 날을 적는다** — 「지방재정365(lofin365.go.kr), 행정안전부 · 2026-09-23 받음」.
9. **한 번에 수십 개를 훑지 않는다.** 스크립트는 쪽 사이에 쉬어 간다. 상대 서버를 몰아치지 않는다.

## 3. 스크립트 — 파이썬 기본 기능만 쓴다(설치할 것 없음)

★명령의 `python3` 는 **윈도우에서는 `python`** 이다(윈도우에는 대개 `python3` 이름이 없다).

```bash
# 지방재정365 · 열린재정 · 경기데이터드림 — 모양이 같다
python3 scripts/lofin.py RHJDKD --peek                        # 칸 이름·뜻·총건수
python3 scripts/lofin.py RHJDKD --fyr 2024 --all --csv 현금성복지비_2024.csv
python3 scripts/openfiscal.py GovernmentDebtYear --all --csv 국가채무.csv
python3 scripts/ggdream.py <자료이름> --peek
#   --이름 값 은 전부 그대로 거르개로 넘어간다 · --sum 칸[,칸] --by 칸[,칸] 은 묶어 더한다(전체 쪽을 받는다)

# KOSIS
python3 scripts/kosis.py search "사업체 종사자"
python3 scripts/kosis.py data 133 TX_13301_A075 --최근 5 --csv 세수.csv

# ECOS
python3 scripts/ecos.py search 기준금리
python3 scripts/ecos.py data <통계표코드> --주기 M --기간 202401 202412

# 목록이 지금 사이트와 같은지 — 자료원마다 (5절)
python3 scripts/lofin.py 대조        # 한 번 부른다. 키 불필요
python3 scripts/kosis.py 대조        # 1분쯤
```

★csv 는 엑셀에서 바로 열리게 저장한다(UTF-8 BOM). **받은 뒤 눈으로 확인한다** — 연도·지역·단위가 맞는지.

- **스킬 폴더에 쓸 수 없는 자리**:
  **고친 파일을 만들어 사용자에게 주고**, 「스킬 폴더(0절 ①의 자리)에 덮어 넣으십시오」라고 안내한다. `대조 --고치기` 는 새 목록 파일을 지금 폴더에 낸다 — **그 경로를 사용자에게 알린다.**
  사용자가 원하면 **스킬을 만든 사람에게 보낼 보고문**도 함께 써 준다.

### 고칠 때 지키는 것

- ★**키 값·개인 정보·사용자의 자료를 스킬 파일에 넣지 않는다.** 새 zip 에도 넣지 않는다.
- **있던 함정을 근거 없이 지우지 않는다.** 틀렸으면 「○월 ○일 재 보니 달랐다」와 함께 고친다.
- **목록 파일은 손으로 고치지 않는다** — `대조 --고치기` 로 사이트에서 다시 받는다. 새 목록이 비었거나 옛것의 절반도 안 되면 스크립트가 쓰지 않고 멈춘다 — 그때는 사이트 모양이 바뀐 것이니 고치지 말고 보고한다.
- **날짜를 적는다.** 이 스킬의 사실은 전부 «그날 재 본 것»이다.

## 5. 목록은 낡는다 — 언제 `대조` 를 돌리나

레퍼런스 목록(지방재정365 · 열린재정 · 국세통계 · ECOS · 경기데이터드림 — 건수는 각 목록 파일 첫 줄)은 **받은 날의 것**이다. 사이트는 자료를 더하고 빼고 이름을 바꾼다.

- 찾는 자료가 **목록에 없을 때**
- 목록에 있는 코드로 불렀는데 **「해당 서비스·표 없음」**(지방재정365·열린재정·경기데이터드림 `ERROR-310`, 경기데이터드림 `ERROR-500`, KOSIS `err 21`, ECOS 코드·기간이 맞는데 `INFO-200`)이 날 때
- 이 스킬을 **오래 안 썼을 때** — 첫 호출 전에 한 번

→ 그 자료원의 `대조` 를 돌린다. **달라졌으면 4절에 따라 보고하고 고친다.**
