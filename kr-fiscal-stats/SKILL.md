# 한국 재정·통계 자료 받아오기 — 다섯 곳

쓰는 사람은 「무슨 자료가 필요한지」만 말한다. **어디서 받을지 고르고, 코드를 찾고, 인자를 맞추는 것은 이 문서가 시킨다.**
자료원마다 함정·목록·칸 뜻은 `references/` 에 따로 있다 — **고른 자료원의 레퍼런스를 먼저 읽고 부른다.**

## 0. ★처음 세팅 — 이것을 먼저 한다

이럴 때 이 절을 따른다 — 사용자가 «세팅해 줘»·«설치해 줘»라고 할 때, 이 스킬을 처음 쓰는 대화일 때, 부르다가 «인증키가 설정되어 있지 않습니다»·«닿지 못했습니다»가 나올 때.
안내하는 말은 저장소의 README·`설치와-사용.md` 와 같게 한다 — 사람은 그 문서를 함께 본다.

### ① 어디서 쓰는지 먼저 묻는다

> 클로드 데스크탑 «코드» 탭에서 **1) 로컬 세션**으로 쓰시나요, **2) 클라우드 세션(프로젝트 스레드 포함)**으로 쓰시나요?

- 지금 세션의 환경변수 `CLAUDE_CODE_REMOTE` 가 `true` 면 클라우드 세션이다. «지금은 2) 로 보입니다»라고 권하되 그래도 묻는다 — 다른 자리에서 쓸 것을 미리 세팅할 수도 있다.
- **프로젝트 스레드는 기본이 클라우드다.** 프로젝트에서도 입력칸 옆 **+ → Work locally** 로 내 PC 에서 돌리면 1) 로컬과 같다. 이 길을 먼저 권한다.
  준비: 데스크탑 설정 → Claude Code → «Use this computer from your phone and claude.ai» 켜고 폴더 더하기, 클로드 코드 v2.1.280 이상. 뜨는 카드에서 폴더를 고르고 «Allow once».
- 터미널에서 쓰는 클로드 코드는 1) 로컬과 같다.
- 1) 로컬의 스킬 폴더 자리: 윈도우 `C:\Users\<이름>\.claude\skills\kr-fiscal-stats` · 맥 `~/.claude/skills/kr-fiscal-stats`(`SKILL.md` 가 바로 보이게). 코드 탭에서 안 보이면 연 작업 폴더 안의 `.claude/skills/kr-fiscal-stats` 에 넣는다. 넣은 뒤 새 세션을 연다.
- **Cowork·일반 채팅은 지금 안 된다** — 스크립트가 클라우드에서 도는데 키를 넣을 자리와 도메인을 열 방법이 없다. 거기서 불렸으면 그렇다고 한 줄 알리고 코드 탭으로 옮기게 한다.

### ③ 키 넣는 법을 말하기 «전»에 설명서 PDF 를 먼저 보여 준다

설명서(사이트 화면 그림으로 따라 하기): https://github.com/Taeyeon1607/kr-fiscal-stats/blob/main/docs/kr-fiscal-stats-인증키-받기.pdf

- 1) 로컬이면 `python3 -m webbrowser "<위 주소>"`(윈도우는 `python`)로 브라우저에 열어 준다. 안 열리면 주소만 준다.
- 2) 클라우드면 주소만 주고 «이 PDF 는 키 받는 절차용입니다. 키를 넣는 법은 지금 안내를 따르십시오»를 함께 적는다(PDF 의 «어디서 쓰나요»와 끝 쪽은 로컬 기준이다).
- 사용자가 «키를 받았다»고 하면 ④ 나 ⑤ 로 간다.

### ④ 1) 로컬 — 키 넣는 창

사용자에게 «키 넣는 창을 띄울까요?»라고 묻고, 좋다고 하면 `python3 scripts/setkey.py <이름>`(윈도우는 `python`)을 고른 곳마다 돌린다.
- 창에는 발급 화면으로 가는 단추와 키 붙여넣기 칸이 있고, 사용자가 직접 붙여 넣고 «저장»을 누른다. 저장하면 홈 폴더의 `~/.<이름>_key` 에 한 줄로 들어간다.
- 종료코드: **0** 저장함(새 세션 없이 바로 원래 명령을 다시 돌린다) · **1** 저장 안 하고 닫음 · **2** 이름이 틀림 · **3** 창을 못 띄우는 자리(tkinter·화면 없음) · **4** 파일을 못 씀.
- **3 이 나면** 아래 «창이 안 될 때» 길을 알려 주고 멈춘다. 키를 대화창에 붙이라고 하지 않는다.
- 창에 «환경변수가 이미 있어 그 값이 먼저 쓰입니다»가 뜨면, 새 키를 쓰려면 사용자가 그 환경변수를 고쳐야 한다.
- **창이 안 될 때** — 사용자가 직접: `~/.claude/settings.json`(윈도우 `C:\Users\<이름>\.claude\settings.json`)의 `"env"` 칸에 `"LOFIN_API_KEY": "키"` 처럼 넣고 새 세션을 열거나, 홈 폴더에 `.lofin_key` 파일을 만들고 키만 한 줄 넣는다.

### ⑤ 2) 클라우드 — 세 단계

클라우드 세션은 Anthropic 클라우드에서 돈다. 내 PC 의 스킬 폴더·키 파일을 못 읽고 키 넣는 창도 안 뜬다. 사용자가 아래 셋을 직접 한다.

1. **스킬을 claude.ai 계정에 올린다** — 클라우드·프로젝트 스레드는 내 PC 에 깐 스킬을 안 읽는다(프로젝트 스레드는 저장소 안 `.claude/skills` 도 안 읽는다).
   claude.ai 또는 데스크탑의 Customize → Skills → «+» → Upload a skill 에 ZIP 을 올린다.
   ZIP 은 맨 위가 `kr-fiscal-stats/SKILL.md` 여야 한다 — 저장소의 Releases 에 붙은 `kr-fiscal-stats.zip` 을 받거나, 저장소에서 `python3 tools/make-skill-zip.py` 로 만든다. GitHub «Download ZIP» 은 맨 위 폴더가 달라 그대로는 안 된다.
2. **클라우드 환경을 연다** — 데스크탑 설정 → 환경 → 클라우드 환경 → 추가(또는 편집). 프로젝트 스레드는 **프로젝트 설정 → Environment** 에 고른 환경을 쓴다.
   - **네트워크 액세스**: «사용자 지정(Custom)» → «허용된 도메인»에 고른 곳만 한 줄씩. 기본(Trusted) 목록에는 이 다섯 곳이 없다. «패키지 관리자 허용(기본 목록 포함)»은 켠 채로 둔다.

     | 자료원 | 허용된 도메인 |
     |---|---|
     | 지방재정365 | `www.lofin365.go.kr` |
     | 열린재정 | `openapi.openfiscaldata.go.kr` · `www.openfiscaldata.go.kr`(목록 대조) |
     | KOSIS | `kosis.kr` |
     | 한국은행 ECOS | `ecos.bok.or.kr` |
     | 경기데이터드림 | `openapi.gg.go.kr` |

   - **환경 변수**: 고른 곳마다 `KOSIS_API_KEY=발급받은키` 처럼 한 줄씩(이름은 ② 표). 스크립트는 환경변수를 키 파일보다 먼저 읽는다.
   - **혼자 쓰는 환경에만** 넣는다. 그 환경을 쓰는 사람은 환경 변수를 볼 수 있다. 조직 공유 환경이나 다른 사람과 나눈 환경에는 넣지 않는다.
   - «네트워크 시크릿»은 쓰지 않는다 — 이 스킬로 시험된 적이 없고, 한국은행은 키가 주소 경로에 들어가 안 될 가능성이 크다.
3. **그 환경으로 새 세션(새 스레드)을 연다.** 바꾼 환경은 새 세션부터 먹는다.

★이 길은 공식 문서(code.claude.com — cloud-environments·claude-projects·skills, 2026-10-22 읽음)대로 적은 것이다. 처음 쓸 때 키를 쓰는 실제 호출 한 번(예: `python3 scripts/kosis.py search 국세 --개수 1`)으로 확인한다. 저장된 목록만 읽고 답했으면 확인한 것이 아니다.
★안 되면 원인을 단정하지 않고 셋을 따로 본다(키 값은 찍지 않는다) — 변수가 있나(`test -n "$KOSIS_API_KEY" && echo 있음 || echo 없음`) · «닿지 못했습니다»면 허용된 도메인 · 사이트가 키 오류를 주면 키 값.

<HARD-GATE>
★**키는 사용자가 직접 넣는다. 클로드는 키 넣는 창(`setkey.py`)을 띄우거나 넣는 법을 알려 줄 뿐이다.** 키를 받아 파일·설정·환경에 적어 주지 않는다.
★**스킬 폴더 안(ZIP 안)에 키를 넣게 하지 않는다.** 스킬을 넘기면 키가 따라간다. 스크립트도 그 자리를 찾지 않는다.
★**키 값을 대화창에 붙여 넣게 하지 않는다.** 붙여 넣으면 그 대화 기록에 그대로 남는다. 이미 붙여 넣었으면 그 키는 폐기하고 다시 발급받도록 권한다.
★**키가 든 파일·환경변수를 화면에 출력하지 않는다.** 있는지 없는지만 확인한다.
</HARD-GATE>

### ⑥ 로컬에서 「닿지 못했습니다」가 나올 때

로컬 코드 탭 세션은 보통 막히지 않는다. 그래도 나오면 스크립트가 찍은 도메인 이름을 그대로 전하고, 회사망 방화벽·상대 서버 장애·인터넷 연결을 확인하게 한다.
클라우드 세션이면 그 도메인이 «허용된 도메인»에 없는 것일 수 있다 — ⑤-2 를 확인한다. 들어 있는데도 나오면 상대 서버 장애·시간 초과일 수 있다.
★코덱스는 같은 스킬 폴더 꼴(`~/.agents/skills/kr-fiscal-stats`)을 받지만 바깥 사이트가 기본으로 막혀 있어 네트워크를 켜야 한다(켜는 법·키를 읽는지는 확인 못 함).

## 2. 다섯 곳 공통 규칙

1. **첫 호출은 언제나 1건만** — `--peek`(ECOS·KOSIS 는 짧은 기간)으로 칸 이름·총건수·단위를 먼저 본다.
2. **거르개를 넣었으면 총건수가 줄었는지 본다.** 모르는 인자를 **조용히 무시하는** 곳이 있다 — 줄지 않았으면 안 먹은 것이다.
3. **HTTP 상태로 성패를 가르지 않는다.** 다섯 곳 모두 오류를 200(열린재정은 201) 안의 본문으로 준다. 스크립트가 가려 준다.
4. **단위를 단정하지 않는다.** 단위가 안 적힌 자료가 많고, 한 자료 안에서도 칸마다 다르다. 크기로 맞춰 추정했으면 **「추정」이라고 밝힌다.**
5. **예산인지 결산인지, 당초인지 최종인지** 이름으로 가르지 말고 구분 칸을 본다(각 레퍼런스의 함정).
6. **더하거나 나누었으면 그렇게 했다고 밝힌다** — 어느 칸을 더했는지까지. `--sum` 결과는 원자료에 없는 수다.
7. **없는 값을 지어내지 않는다.** 빈 결과는 「그 조건에 자료가 없다」고 말한다.
8. **출처와 받은 날을 적는다** — 「지방재정365(lofin365.go.kr), 행정안전부 · 2026-09-23 받음」.
9. **한 번에 수십 개를 훑지 않는다.** 스크립트는 쪽 사이에 쉬어 간다. 상대 서버를 몰아치지 않는다.

## 3. 스크립트 — 파이썬 기본 기능만 쓴다(설치할 것 없음)

★명령의 `python3` 는 **윈도우에서는 `python`** 이다(윈도우에는 대개 `python3` 이름이 없다).

```bash
# 지방재정365 · 열린재정 · 경기데이터드림 — 모양이 같다
```

## 4. ★★스킬 스스로 고치기 — 반드시 한다

<HARD-GATE>
**이 스킬을 쓰다가 아래 넷 중 하나를 만나면, 그 대화 안에서 «사용자에게 보고»하고 «스킬을 고친다».**
그냥 우회해서 답만 내고 넘어가지 않는다 — 다음 사람이 같은 자리에서 또 헤맨다.

1. **API 가 바뀌었다** — 목록에 없는 자료가 생겼거나 없어졌다, 이름·인자·칸이 달라졌다, 주소가 바뀌었다.
2. **이 스킬의 지침이 틀려서 시행착오를 겪었다** — 적힌 대로 했는데 오류가 났고 다른 방법으로 풀렸다.
3. **적혀 있지 않은 함정을 만났다** — 단위, 필수 인자, 칸 뜻, 같은 이름이 여러 번 나오는 것 따위.
4. **그 밖에 고치면 나아질 것**을 찾았다 — 빠진 예시, 헷갈리는 문장, 자주 쓰는데 목록에서 찾기 어려운 자료.
</HARD-GATE>

### 어떻게 보고하나 — 답의 끝에 한 덩어리로

> **[스킬 개선 제안]** 무엇이 틀렸나(파일·절) · 실제로는 어땠나(부른 명령과 결과) · 어떻게 고치나(바꿀 문장).

★**재 본 것만 적는다.** 한 번 본 것은 「한 번 확인」이라고, 추정은 「추정」이라고 적는다.

### 어떻게 고치나 — 자리에 따라 둘

- **스킬 폴더에 쓸 수 있는 자리**(클로드 코드 등 — `~/.claude/skills/kr-fiscal-stats/`):
  해당 레퍼런스·SKILL.md 를 **직접 고치고**, `references/고친-기록.md` 맨 아래에 한 줄을 더한다
  (`날짜 · 무엇을 · 왜 · 어떻게 확인했나`). 목록이 달라졌으면 `대조 --고치기` 를 돌린다.
- **스킬 폴더에 쓸 수 없는 자리**:
  **고친 파일을 만들어 사용자에게 주고**, 「스킬 폴더(로컬은 0절 ①의 자리)에 덮어 넣으십시오 — 클라우드는 고친 폴더로 ZIP 을 다시 만들어 계정 스킬에 다시 올리십시오」. ZIP 을 만드는 `tools/make-skill-zip.py` 는 ZIP 안에 없다 — ZIP 만 받은 사람에게는 «저장소(https://github.com/Taeyeon1607/kr-fiscal-stats)를 받아 그 안의 `kr-fiscal-stats/` 폴더를 고친 폴더로 바꾸고 `python3 tools/make-skill-zip.py` 로 다시 묶어 올리십시오»라고 안내한다라고 안내한다. `대조 --고치기` 는 새 목록 파일을 지금 폴더에 낸다 — **그 경로를 사용자에게 알린다.**
  사용자가 원하면 **스킬을 만든 사람에게 보낼 보고문**도 함께 써 준다.

### 고칠 때 지키는 것

- ★**키 값·개인 정보·사용자의 자료를 스킬 파일에 넣지 않는다.** 새 zip 에도 넣지 않는다.
- **있던 함정을 근거 없이 지우지 않는다.** 틀렸으면 「○월 ○일 재 보니 달랐다」와 함께 고친다.
- **목록 파일은 손으로 고치지 않는다** — `대조 --고치기` 로 사이트에서 다시 받는다. 새 목록이 비었거나 옛것의 절반도 안 되면 스크립트가 쓰지 않고 멈춘다 — 그때는 사이트 모양이 바뀐 것이니 고치지 말고 보고한다.
- **날짜를 적는다.** 이 스킬의 사실은 전부 «그날 재 본 것»이다.

## 5. 목록은 낡는다 — 언제 `대조` 를 돌리나

레퍼런스 목록(지방재정365 · 열린재정 · 국세통계 · ECOS · 경기데이터드림 — 건수는 각 목록 파일 첫 줄)은 **받은 날의 것**이다. 사이트는 자료를 더하고 빼고 이름을 바꾼다.

- 찾는 자료가 **목록에 없을 때**
- 목록에 있는 코드로 불렀는데 **「해당 서비스·표 없음」**(지방재정365·열린재정·경기데이터드림 `ERROR-310`, 경기데이터드림 `ERROR-500`, KOSIS `err 21`, ECOS 코드·기간이 맞는데 `INFO-200`)이 날 때
- 이 스킬을 **오래 안 썼을 때** — 첫 호출 전에 한 번

→ 그 자료원의 `대조` 를 돌린다. **달라졌으면 4절에 따라 보고하고 고친다.**
