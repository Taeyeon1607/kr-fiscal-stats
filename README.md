# kr-fiscal-stats — 한국 재정·통계 자료를 말로 받아 오는 클로드 스킬

클로드에게 **「수원시 2024년 재정자립도 받아 줘」** 처럼 말하면, 클로드가 알맞은 공공 API를 골라 자료를 받아 옵니다.
API 주소나 코드를 몰라도 됩니다. 받은 자료는 표로 보여 주거나 엑셀에서 열리는 파일(csv)로 저장해 줍니다.

이런 것을 할 수 있습니다.

- 「경기도 31개 시군 2024년 세출예산을 엑셀 파일로 받아 줘」
- 「2020년부터 국가채무 추이를 표로 보여 줘」
- 「최근 5년 세목별 국세 징수액 받아 줘」
- 「올해 한국은행 기준금리 추이 보여 줘」
- 「경기도가 공개한 공공도서관 목록 받아 줘」

## 1. 어떤 자료를 받을 수 있나

공공 API 다섯 곳에서 받습니다.

| 자료원 | 무엇이 있나 | 스킬이 찾는 법 |
|---|---|---|
| **지방재정365** | 시·군·구, 시·도의 예산·결산·세입·세출·재정자립도·지방채·복지비 | 자료 146개 목록과 칸마다의 뜻(1,395칸), 자치단체 코드가 스킬 안에 들어 있음 |
| **열린재정** | 중앙정부(국가)의 예산·결산·국가채무·기금·부처별 집행 | 198종 목록이 스킬 안에 들어 있음 |
| **KOSIS 국가통계포털** | 국가 공식 통계 전부(인구·고용·사업체·가계·산업·국세 등) | 국세통계 표 목록만 들어 있음. 나머지는 KOSIS 검색으로 찾음 |
| **한국은행 ECOS** | 금리·물가·환율·통화·국민계정(GDP)·국제수지 | 통계표 617개 목록이 스킬 안에 들어 있음 |
| **경기데이터드림** | 경기도가 공개한 자료(시설·인허가·지원사업·현황 목록 등) | 2,128개 목록이 스킬 안에 들어 있음 |

- **목록이 들어 있는 네 곳**은 클로드가 그 목록에서 코드를 바로 고릅니다.
- **KOSIS** 는 표가 29만 개라 목록을 담지 못합니다. 그래서 KOSIS 검색에 낱말로 물어 맞는 표를 고릅니다.
- 쓰지 않을 자료원은 키를 받지 않아도 됩니다. **필요한 곳만** 준비하면 됩니다.

헷갈리기 쉬운 짝은 클로드가 알아서 가릅니다.

- 「지방세」는 지방재정365, 「국세」는 KOSIS 국세통계입니다.
- 「국가 예산」은 열린재정, 「OO시 예산」은 지방재정365입니다.
- 「경기도 시군 재정」도 경기데이터드림이 아니라 지방재정365에서 받습니다.

## 2. 어디서 쓸 수 있나

이 스킬은 **내 컴퓨터에서 작은 프로그램(파이썬 스크립트)을 돌려** 자료를 받습니다.
그래서 내 컴퓨터에서 스크립트를 돌릴 수 있는 곳에서만 씁니다.

| 어디서 | 쓸 수 있나 |
|---|---|
| **클로드 코드** | ✅ 됩니다 |
| **클로드 데스크탑의 «코드» 탭** | ✅ 됩니다 |
| 코덱스(CLI·앱) | △ 스킬은 받습니다. 다만 바깥 사이트 접속이 기본으로 막혀 있어 네트워크를 켜야 합니다. 켜는 법과 키를 읽는지는 확인 못 함입니다 |
| 클로드 데스크탑의 «일반 채팅»(스킬 zip 올리기) | ❌ 맞지 않습니다 — 스크립트가 클라우드에서 돌아 내 컴퓨터의 키를 못 읽습니다 |
| ChatGPT 웹 | ❌ 맞지 않습니다 — 같은 까닭입니다(세부는 확인 못 함) |
| 클로드 «코워크» | 확인 못 함 |

> **처음이라면 클로드 데스크탑의 «코드» 탭이나 클로드 코드를 쓰십시오.**

## 3. 준비물

1. **클로드 코드**, 또는 **클로드 데스크탑**(«코드» 탭을 씁니다)
2. **파이썬 3** — 스크립트는 파이썬 기본 기능만 써서 따로 설치할 것은 없습니다. 파이썬만 있으면 됩니다.
   - 윈도우·맥 모두 **https://www.python.org/downloads/** 에서 받는 것을 권합니다.
   - 윈도우 설치 화면에서 **«Add python.exe to PATH»** 칸을 켜 주십시오. 그리고 선택 기능의 **«tcl/tk and IDLE»** 칸은 끄지 마십시오 — 키 넣는 창이 이 기능을 씁니다.
   - 맥에 처음부터 들어 있는 파이썬(`/usr/bin/python3`)은 키 넣는 창이 이상하게 그려지거나 멈출 수 있습니다. python.org 의 파이썬을 쓰십시오.
3. 쓸 자료원의 **인증키** — [5. 인증키 받기](#5-인증키-받기)에서 받습니다.

## 4. 설치 — 폴더 하나를 넣으면 끝

### ① 스킬 폴더 내려받기

이 저장소 화면 위쪽의 초록색 **«Code»** 단추 → **«Download ZIP»** 을 누릅니다.
받은 zip 의 압축을 풀면 안에 **`kr-fiscal-stats`** 폴더가 있습니다. 이 폴더 하나만 옮기면 됩니다.

### ② 그 폴더를 스킬 폴더에 넣기

`kr-fiscal-stats` 폴더를 **통째로** 아래 자리에 넣습니다. `skills` 폴더가 없으면 새로 만듭니다.

**클로드 코드 · 클로드 데스크탑 «코드» 탭**

| 컴퓨터 | 넣을 자리 |
|---|---|
| 윈도우 | `C:\Users\<내 사용자 이름>\.claude\skills\kr-fiscal-stats` |
| 맥 | `~/.claude/skills/kr-fiscal-stats` (홈 폴더 안의 `.claude` → `skills`) |

★클로드 데스크탑 «코드» 탭도 같은 폴더를 읽는 것으로 압니다. 직접 확인하지는 못했습니다.
  코드 탭에서 스킬이 안 보이면, 코드 탭에서 연 작업 폴더 안에 `.claude\skills\kr-fiscal-stats`(맥은 `.claude/skills/kr-fiscal-stats`)로 넣어 주십시오. 그러면 그 작업 폴더에서 쓰입니다.

**코덱스**

| 컴퓨터 | 넣을 자리 |
|---|---|
| 윈도우 | `C:\Users\<내 사용자 이름>\.agents\skills\kr-fiscal-stats` |
| 맥 | `~/.agents/skills/kr-fiscal-stats` |

다 넣었을 때 이렇게 보이면 맞습니다.

```
.claude
└─ skills
   └─ kr-fiscal-stats
      ├─ SKILL.md
      ├─ 설치와-사용.md
      ├─ references
      └─ scripts
```

★`kr-fiscal-stats` 안에 `kr-fiscal-stats` 가 한 번 더 들어가지 않게 하십시오. `SKILL.md` 가 바로 보여야 합니다.

<details>
<summary><b>.claude 폴더가 안 보일 때</b> (이름이 점으로 시작하는 폴더는 숨겨져 있습니다)</summary>

- **윈도우** — 파일 탐색기 위쪽 주소창에 `%USERPROFILE%\.claude` 를 넣고 Enter 를 누릅니다.
  폴더가 없다고 나오면 클로드 코드나 데스크탑 «코드» 탭을 한 번 연 뒤 다시 해 봅니다.
- **맥** — Finder 에서 ⌘+Shift+G 를 누르고 `~/.claude` 를 넣습니다. 숨은 폴더를 보이게 하려면 ⌘+Shift+. (마침표)를 누릅니다.

</details>

### ③ 새 대화 열기

넣은 뒤에는 **새 대화(새 세션)** 를 엽니다. 이미 열려 있던 대화는 새 스킬을 모릅니다.

## 5. 인증키 받기

자료원마다 **인증키**(API 키)가 따로 있습니다. 각 사이트에서 회원가입·로그인을 한 뒤 신청합니다.

| 자료원 | 신청하는 곳 | 키 이름 |
|---|---|---|
| 지방재정365 | https://www.lofin365.go.kr → 위 메뉴 「재정데이터개방」 → 인증키 신청 | `LOFIN_API_KEY` |
| 열린재정 | https://www.openfiscaldata.go.kr/op/ko/ds/UOPKODSA01.do → 인증키 발급 | `OPENFISCAL_API_KEY` |
| KOSIS | https://kosis.kr/openapi/serviceUse/serviceUseUnityReg_01Detail.do → 활용신청 | `KOSIS_API_KEY` |
| 한국은행 ECOS | https://ecos.bok.or.kr/api/#/AuthKeyApply | `ECOS_API_KEY` |
| 경기데이터드림 | https://data.gg.go.kr/portal/openapi/insertApikeyPage.do | `GGDREAM_API_KEY` |

- 지방재정365는 바로 가는 주소가 없습니다. 첫 화면에서 메뉴를 따라 들어갑니다.
- 사이트마다 화면을 그림으로 따라가는 설명서는 함께 드리는 **PDF 설명서**([`docs/kr-fiscal-stats-인증키-받기.pdf`](docs/kr-fiscal-stats-인증키-받기.pdf))에 있습니다.
- 키를 미리 받아 두지 않아도 됩니다. 다음 절의 «키 넣는 창»에 발급 화면으로 가는 단추가 있습니다.

## 6. 인증키 넣기

### 가장 쉬운 길 — 키 넣는 창

명령어나 설정 파일을 몰라도 됩니다.

1. 클로드에게 **「지방재정365 키 넣어 줘」** 처럼 말합니다. (자료를 부탁했는데 키가 없을 때도 클로드가 먼저 묻습니다.)
2. 클로드가 «키 넣는 창을 띄울까요?» 하고 묻습니다. **좋다**고 답합니다.
3. 이런 창이 뜹니다(윈도우 화면, 사용자 이름은 가림).

   ![지방재정365 인증키 넣기 창 — 발급 받으러 가기, 키 칸과 붙여넣기, 키 글자 보기, 저장할 곳, 닫기·저장 단추](docs/win-window.png)

4. 키가 아직 없으면 **«발급 받으러 가기»** 를 누릅니다. 그 자료원의 발급 화면이 열립니다. 키를 받아 복사합니다.
5. **«붙여넣기»** 단추를 누르거나 칸을 누르고 Ctrl+V(맥은 ⌘+V)를 누릅니다. 키는 `*` 로 가려 보입니다. 확인하려면 «키 글자 보기»를 켭니다.
6. **«저장»** 을 누릅니다. 이미 넣은 키가 있으면 바꿀지 묻습니다.
7. 클로드에게 **하던 부탁을 다시** 하면 됩니다. 새 대화를 열 필요는 없습니다.

★창에 넣은 키는 대화 기록에 남지 않습니다. 클로드도 키를 보지 않습니다.
★키는 홈 폴더의 작은 파일(예: `.lofin_key`)에 한 줄로 저장됩니다. 스킬 폴더 안에는 저장하지 않습니다.
★다섯 곳을 다 쓰려면 자료원마다 한 번씩 넣습니다 — 「열린재정 키 넣어 줘」, 「KOSIS 키 넣어 줘」…

<details>
<summary><b>그 밖의 방법</b> — 창이 안 뜰 때, 또는 직접 넣고 싶을 때</summary>

스크립트는 키를 **두 곳에서만** 찾습니다 — **환경변수**, 또는 **홈 폴더의 `.<이름>_key` 파일**. 둘 다 있으면 환경변수가 먼저입니다.

**ⓐ 클로드 코드 · 데스크탑 «코드» 탭의 `settings.json`**

파일 자리: 윈도우 `C:\Users\<내 사용자 이름>\.claude\settings.json`, 맥 `~/.claude/settings.json`.
이미 다른 칸이 있으면 `env` 칸만 더합니다. 쓰는 자료원만 넣으면 됩니다.

```json
{
  "env": {
    "LOFIN_API_KEY": "발급받은 키",
    "OPENFISCAL_API_KEY": "발급받은 키",
    "KOSIS_API_KEY": "발급받은 키",
    "ECOS_API_KEY": "발급받은 키",
    "GGDREAM_API_KEY": "발급받은 키"
  }
}
```

넣은 뒤 새 대화를 엽니다.

**ⓑ 운영체제 환경변수**

- 윈도우: 시작 메뉴에서 «계정의 환경 변수 편집»을 열고, 사용자 변수에 `LOFIN_API_KEY` = 키 를 더합니다.
- 맥: `~/.zshrc` 에 `export LOFIN_API_KEY=키` 한 줄을 더합니다.

**ⓒ 홈 폴더 파일을 손으로**

홈 폴더(윈도우 `C:\Users\<내 사용자 이름>`, 맥 `~`)에 아래 이름의 파일을 만들고 **키만 한 줄** 넣습니다. 키 넣는 창이 하는 일과 같습니다.

| 자료원 | 파일 이름 |
|---|---|
| 지방재정365 | `.lofin_key` |
| 열린재정 | `.openfiscal_key` |
| KOSIS | `.kosis_key` |
| 한국은행 ECOS | `.ecos_key` |
| 경기데이터드림 | `.ggdream_key` |

</details>

## 7. 처음 써 보기

새 대화를 열고 아래처럼 말해 봅니다. 괄호는 클로드가 고르는 자료원입니다.

> 「2024년 수원시 재정자립도 받아 줘」 → (지방재정365)
>
> 「2020년부터 국가채무 추이 표로 보여 줘」 → (열린재정)
>
> 「최근 5년 세목별 국세 징수액 받아 줘」 → (KOSIS 국세통계)
>
> 「올해 한국은행 기준금리 추이 보여 줘」 → (한국은행 ECOS)
>
> 「경기도 시군별 2024년 세출예산을 엑셀 파일로 저장해 줘」 → (지방재정365, csv 파일로 저장)

- 클로드는 언제나 **먼저 1건만** 받아 칸 이름·건수·단위를 확인한 뒤 전체를 받습니다.
- 파일로 저장한 csv 는 **엑셀에서 바로** 열립니다(한글이 깨지지 않게 저장합니다).
- 받은 뒤에는 **연도·지역·단위가 맞는지 눈으로 한 번** 확인하십시오.
- 스크립트가 컴퓨터에서 돌 때 클로드 코드가 «이 명령을 실행해도 될까요?» 하고 물을 수 있습니다. 허락하면 됩니다.

## 8. 잘 안 될 때

| 이런 말이 나오면 | 이렇게 합니다 |
|---|---|
| **키가 없다**는 말 | [6. 인증키 넣기](#6-인증키-넣기)대로 그 자료원의 키를 넣습니다 |
| **「○○ 에 닿지 못했습니다」** | 인터넷이 막혀 있다는 뜻입니다. 아래 «닿지 못할 때»를 봅니다 |
| **0건**, 자료가 없다는 말 | 그 조건에 맞는 자료가 정말 없을 수 있습니다. 연도·지역을 바꿔 봅니다. 통계(KOSIS)는 낱말을 짧게 — 「경기도 시군별 사업체 수 2023」 대신 「사업체」처럼 |
| **「이 자리에서는 창을 못 띄웁니다」** | 키 넣는 창이 안 뜨는 자리입니다. 아래 «창이 안 뜰 때»를 봅니다 |
| **「해당 서비스·표 없음」**, 찾는 자료가 목록에 없음 | 사이트 목록이 바뀌었을 수 있습니다. 클로드에게 「목록 대조해 줘」라고 하면 지금 사이트 목록과 맞춰 봅니다 |
| **인증서를 확인하지 못했다**는 말 | 허용 목록 문제가 아니라 이 컴퓨터의 인증서 저장소 문제입니다. 회사·기관 컴퓨터라면 전산 담당자에게 문의하십시오 |
| `python3` 을 찾을 수 없다는 말(윈도우) | 윈도우는 `python` 이라는 이름을 씁니다. 클로드에게 「윈도우라 python 으로 돌려 줘」라고 말합니다. 그래도 안 되면 [3. 준비물](#3-준비물)대로 파이썬을 설치합니다 |

<details>
<summary><b>닿지 못할 때</b> — 도메인 허용 목록</summary>

클로드 데스크탑은 스크립트가 나가는 주소를 **허용 목록**으로 막을 수 있습니다. 오류 문장에 넣을 도메인이 적혀 나옵니다.

설정 → **기능** → 「**외부 네트워크 접속 허용**」 켜기 → 「**추가 허용 도메인**」에 쓸 곳의 도메인을 넣습니다. 넣은 뒤 **새 대화**에서 다시 합니다.

|---|---|
| 지방재정365 | `www.lofin365.go.kr` |
| 열린재정 | `openapi.openfiscaldata.go.kr` |
| KOSIS | `kosis.kr` |
| 한국은행 ECOS | `ecos.bok.or.kr` |
| 경기데이터드림 | `openapi.gg.go.kr` |

코덱스는 바깥 사이트 접속이 기본으로 막혀 있어 네트워크를 켜야 합니다.

</details>

<details>
<summary><b>창이 안 뜰 때</b></summary>

키 넣는 창은 파이썬의 창 기능(tkinter)을 씁니다. 이것이 없거나 화면을 띄울 수 없는 자리면 창이 안 뜹니다.

- **윈도우** — python.org 의 파이썬에는 창 기능이 들어 있습니다. 설치할 때 «tcl/tk and IDLE» 칸을 껐다면 파이썬을 다시 설치하며 켭니다.
- **맥** — python.org 의 파이썬을 씁니다. 맥에 처음부터 있는 `/usr/bin/python3` 는 창이 이상하게 그려지거나 멈출 수 있습니다. 홈브루(Homebrew) 파이썬이라면 `brew install python-tk` 를 따로 해야 합니다. 맥에서는 아직 직접 확인하지 못했습니다.
- **클로드 데스크탑 «일반 채팅»** — 클라우드에서 돌아 내 화면에 창이 안 뜹니다. [2. 어디서 쓸 수 있나](#2-어디서-쓸-수-있나)를 봅니다.

창 없이 넣으려면 [6. 인증키 넣기](#6-인증키-넣기)의 «그 밖의 방법»을 씁니다.

</details>

## 9. 키와 개인정보 — 꼭 지킬 것

- **키를 클로드 대화창에 붙여 넣지 마십시오.** 대화 기록에 그대로 남습니다. 이미 붙여 넣었다면 그 키는 사이트에서 폐기하고 다시 받으십시오.
- **스킬 폴더(`kr-fiscal-stats`) 안에 키를 넣지 마십시오.** 스킬을 남에게 주면 키가 함께 갑니다. 스크립트도 그 자리에서는 키를 찾지 않습니다.
- **키가 든 파일(`.lofin_key` 등)과 `settings.json` 을 남에게 보내지 마십시오.**
- 클로드는 키를 받아 대신 넣어 주지 않습니다. 키는 언제나 직접 넣습니다.
- 스크립트는 키 값을 화면에 찍지 않습니다.

## 10. 자료를 쓸 때 — 출처와 주의

**출처 표기** — 받은 자료를 남에게 보일 때는 출처를 밝힙니다. 자료원 이름(기관, 통계표나 자료 이름), 받은 날짜를 적습니다.

> 예: 출처: ECOS(한국은행, 통계표명), 받은 날짜

KOSIS 와 ECOS 는 출처를 밝히는 것이 이용 조건입니다. ECOS 의 다른 기관 통계표는 비상업적 목적으로만, 경기데이터드림 자료를 상업적으로 쓰려면 경기도 승인이 필요합니다. 기관별 조건은 저장소의 [`NOTICE`](NOTICE)에 모아 두었습니다.

클로드도 답에 출처와 받은 날을 적습니다.

**알아 둘 것**

- **금액 단위가 대개 적혀 있지 않습니다.** 클로드가 크기로 맞춰 추정하면 «추정»이라고 밝힙니다. 보고서에 쓰기 전에 원 사이트에서 단위를 확인하십시오.
- **더한 값·나눈 값은 원자료에 없는 수**입니다. 클로드가 무엇을 더했는지 밝힙니다.
- **예산인지 결산인지, 당초인지 최종인지** 확인하십시오. 자료 이름만으로는 갈리지 않는 경우가 있습니다.
- 스킬 안의 자료 목록은 **받은 날의 것**입니다. 사이트가 바뀌면 낡습니다. 쓰다가 목록이 틀린 것을 만나면 클로드가 답 끝에 **[스킬 개선 제안]** 을 붙이고, 클로드 코드에서는 스킬 파일을 직접 고칩니다.

더 자세한 내용은 스킬 폴더 안의 [`설치와-사용.md`](kr-fiscal-stats/설치와-사용.md)에 있습니다.
